## You will need this folder, place the libs here.

```
// linux
libs/
|── libZRCSdk.so # The ZRCSDK lib
|── libuv.a      # Demo app uses libuv

// windows
|── ZRCSdk.lib   # The ZRCSDK lib
|── dll          # The dll folder

// macOS
|── ZRCSdk.framework # The ZRCSDK framework
|── ...              # Other frameworks and dylibs

```
